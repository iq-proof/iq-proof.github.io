Object detection의 모든 설계 결정 — NMS, anchor, Hungarian matching, mAP — 은 단 하나의 사실에서 나온다. **출력이 고정 크기 벡터가 아니라 가변 크기 집합이다.** 이 집합 구조를 출발점으로 삼으면 왜 NMS가 필요하고, 왜 IoU loss가 L1보다 나으며, 왜 DETR이 NMS를 제거할 수 있는지가 자연스럽게 도출된다. 그 연쇄를 지금부터 추적한다.

## Detection의 출력 공간

분류는 이미지 한 장을 하나의 라벨로 매핑한다. Segmentation은 픽셀마다 라벨을 붙인다. Detection은 "어디에 뭐가 몇 개 있는가"를 답해야 하므로, 출력의 크기가 이미지마다 달라진다.

모델 $f_\theta$의 출력을 정식화하면:

$$
\hat{Y} = \{(\hat{b}_j,\, \hat{c}_j,\, \hat{s}_j)\}_{j=1}^{\hat{N}}, \quad \hat{s}_j \in [0, 1]
$$

여기서 $\hat{N}$은 모델이 결정하는 예측 개수이고, ground-truth의 개수 $N$과 일반적으로 다르다. 이 **variable-size set** 이라는 성질 하나가 아래의 모든 문제를 만든다.

Bounding box 표기법은 두 가지가 공존한다. Center-size form $(c_x, c_y, w, h)$는 regression target에 자연스럽고, corner form $(x_1, y_1, x_2, y_2)$는 IoU 계산에 자연스럽다. 두 표기법은 $w, h > 0$ 조건에서 bijective이므로 정보 손실 없이 변환된다. 단, numerical stability와 loss formulation 편의에 따라 선택이 갈린다.

## IoU — 평가와 학습의 간극

Detection 품질은 IoU로 측정한다.

$$
\text{IoU}(A, B) := \frac{|A \cap B|}{|A \cup B|} \in [0, 1]
$$

그런데 IoU를 **loss function**으로 그대로 쓰면 심각한 문제가 있다.

<Theorem kind="proposition" number="1" title="IoU loss의 disjoint plateau">
$A \cap B = \emptyset$인 모든 box pair에서 $\text{IoU}(A, B) = 0$이고, 거의 모든 disjoint 영역에서 $\nabla_{\hat{b}}\,\text{IoU} = 0$이다.
</Theorem>

<Proof>
$|A \cap B| = 0$이면 정의에 의해 IoU = 0. 작은 perturbation $\hat{b} + \epsilon$이 여전히 disjoint하면 IoU는 계속 0으로 유지된다. 따라서 거의 모든 disjoint 영역에서 gradient가 0이다. $\square$
</Proof>

학습 초기에는 예측 box와 GT box가 겹치지 않는 경우가 흔하다. 이 영역에서 학습 신호가 0이면 모델은 이동 방향을 알 수 없다. GIoU (Rezatofighi et al. 2019)는 이를 해결하기 위해 두 box를 모두 감싸는 최소 외접 사각형 $C$를 도입한다.

$$
\text{GIoU}(A, B) := \text{IoU}(A, B) - \frac{|C \setminus (A \cup B)|}{|C|} \in [-1, 1]
$$

$A \cap B = \emptyset$일 때 GIoU는 $-1 + (|A| + |B|)/|C|$로, 두 box가 멀수록 더 큰 패널티를 부과한다. gradient가 0이 아니므로 학습이 가능하다.

DIoU (Zheng et al. 2020)는 한 box가 다른 box 내부에 완전히 포함될 때 GIoU = IoU라서 추가 신호가 없다는 한계를 center distance penalty로 보완한다. CIoU는 여기에 aspect ratio 차이까지 더한다. 현대 detector(YOLOv5/v8)가 CIoU를 기본값으로 쓰는 이유는 수렴 속도와 최종 IoU 모두 개선되기 때문이다.

<Callout type="note" title="트레이드오프">
**L1/Smooth-L1**: 안정적이고 단순하지만 평가 metric(IoU)과 직접 연결되지 않는다. **GIoU**: disjoint plateau를 해결하지만 포함 관계에서 추가 신호가 없다. **DIoU/CIoU**: 더 풍부한 gradient를 제공하지만 `arctan` 계산에서 numerical 위험이 있고 `alpha` term에 stop-gradient가 필요하다. DETR은 L1 + GIoU를 조합해 set prediction matching cost로 사용한다.
</Callout>

## mAP — 집합 평가 metric

평가 metric도 출력이 집합이라는 사실을 반영해야 한다. confidence threshold $\theta$를 변화시키면서 precision과 recall을 측정하면 PR curve가 만들어지고, AP는 그 곡선 아래 면적이다.

$$
\text{AP} := \int_0^1 p_{\text{interp}}(r)\, dr, \quad p_{\text{interp}}(r) = \max_{\tilde{r} \geq r} P(\tilde{r})
$$

envelope $p_{\text{interp}}$를 사용하는 이유는 raw PR curve가 zigzag를 가질 수 있기 때문이다 — FP 다음 TP가 연속으로 발생하면 recall이 증가하면서 precision이 잠깐 올라간다. Monotone 보정 후 적분한다.

PASCAL VOC 2007의 11-point 근사와 COCO의 all-point 적분은 **같은 PR curve에서 다른 숫자를 준다**. 옛 논문과 현대 논문의 mAP를 직접 비교하면 안 되는 이유다. COCO의 표준 metric은 IoU threshold 10개의 평균이다.

$$
\text{mAP}_{\text{COCO}} = \frac{1}{|\mathcal{T}|} \frac{1}{C} \sum_{\tau \in \mathcal{T}} \sum_{c=1}^{C} \text{AP}_c(\tau), \quad \mathcal{T} = \{0.50, 0.55, \ldots, 0.95\}
$$

mAP@.5 = 0.7인데 mAP@[.5:.95] = 0.3인 모델은 class는 맞추지만 **localization이 부정확**한 모델이다. CIoU loss 도입이나 FPN으로 해상도를 높이는 것이 처방이 된다.

## NMS — 집합 구조가 강제하는 후처리

출력이 집합이라는 사실이 NMS를 필연적으로 만든다.

<Theorem kind="proposition" number="2" title="중복 예측의 FP 강제">
detector가 같은 object에 대해 두 예측 $(\hat{b}_1, c, \hat{s}_1)$, $(\hat{b}_2, c, \hat{s}_2)$를 출력하고 $\text{IoU}(\hat{b}_1, \hat{b}_2) > \tau_{\text{eval}}$이면, 둘 중 하나는 반드시 FP가 된다.
</Theorem>

<Proof>
GT box $b$가 하나뿐이고 $\hat{b}_1, \hat{b}_2$ 모두 $b$와 IoU $\geq \tau$라 하자. TP/FP 매칭 규칙은 GT당 하나의 예측만 TP로 인정한다. confidence sort 후 첫 번째만 매칭되고, 두 번째는 자동으로 FP가 된다. $\square$
</Proof>

Anchor-based / one-stage detector는 dense prediction을 통해 같은 object에 여러 grid cell이 응답하도록 학습한다. 이는 positive sample 다양성을 높여 학습을 안정화시키지만, inference에서는 반드시 중복 제거가 필요하다. Greedy NMS는 confidence 내림차순으로 정렬 후, 선택된 box와 IoU $\geq \tau$인 나머지를 제거하는 $O(N^2)$ 알고리즘이다.

Greedy NMS의 근본 한계는 **crowded scene**에 있다. 두 사람이 가까이 서 있어 IoU = 0.6이면, $\tau = 0.5$로 설정할 경우 두 번째 사람의 예측이 제거되어 FN이 발생한다. Soft-NMS (Bodla et al. 2017)는 hard removal 대신 score decay를 적용한다.

$$
s_j \leftarrow s_j \cdot \exp(-\text{IoU}^2 / \sigma)
$$

Gaussian decay는 모든 IoU에서 score를 단조비증가로 유지하면서, 가까운 박스를 제거하는 대신 confidence를 낮춰 최종 threshold에서 자연스럽게 걸러낸다. COCO에서 약 +1.7 mAP의 개선을 준다.

<Aside label="NMS의 미래">
DETR은 Hungarian matching 기반 set prediction loss로 training-time에 중복 예측 자체를 억제해 NMS를 완전히 제거한다. 그러나 500 epoch의 느린 수렴과 small object 어려움이 따른다. 현재는 scene complexity와 latency 요구에 따라 NMS-based(YOLO 계열)와 NMS-free(RT-DETR) 중 선택하는 양상이다.
</Aside>

## 정리

- Detection 출력은 **variable-size set**이다. 이 사실 하나가 NMS, set prediction loss, mAP, anchor 책임 할당을 모두 도출한다.
- IoU loss는 disjoint 영역에서 gradient가 0이다. GIoU → DIoU → CIoU는 각각 enclosing box 패널티, center distance, aspect ratio를 더해 학습 신호를 풍부하게 했다.
- mAP@.5와 mAP@[.5:.95]는 다른 정보를 측정한다. 논문 숫자를 비교할 때 반드시 metric을 확인해야 한다.
- NMS는 dense prediction의 필연적 귀결이고, Soft-NMS는 crowded scene의 FN을 부드럽게 완화한다. NMS를 없애려면 loss 설계 자체를 바꿔야 한다.

출발점의 수학이 명확하지 않으면, 각 설계 결정이 왜 그 형태인지 알 수 없다.
