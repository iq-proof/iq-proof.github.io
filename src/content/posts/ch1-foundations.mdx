Diffusion Model의 모든 수식은 하나의 물음에서 출발한다 — **노이즈로 무너진 것을 어떻게 복원하는가?** 이 질문은 1905년 Einstein의 브라운 운동 논문에도 있었고, 1982년 Anderson의 Reverse SDE에도 있었으며, 2020년 Ho의 DDPM에서야 비로소 실용적 생성 모델로 착지했다. 물리학의 언어가 머신러닝의 언어로 번역되기까지 무엇이 필요했는가?

## 물리적 직관 — 브라운 운동과 확산

1D 브라운 운동 $X_t = B_t$는 시간에 비례해 분산이 증가한다.

$$\mathbb{E}[X_t^2] = t$$

이 단순한 사실이 forward diffusion의 토대다. 이미지 $x_0$에 매 스텝 작은 가우시안 노이즈를 더하면, $t$가 커질수록 원본 신호는 희미해지고 결국 순수한 노이즈 $\mathcal{N}(0, I)$로 수렴한다. 이것이 물리학에서 말하는 "계가 평형 상태로 완화(relaxation)되는" 과정이다.

역방향으로 생각하면 생성이 된다. 노이즈 $x_T$에서 시작해 각 스텝의 노이즈를 "되감으면" 데이터 $x_0$가 복원된다. 문제는 역방향 과정을 어떻게 수학적으로 기술하느냐다.

## Forward Process — Markov Chain과 분산 보존

DDPM의 forward process는 다음 Markov chain으로 정의된다.

$$q(x_t \mid x_{t-1}) = \mathcal{N}\!\left(\sqrt{1-\beta_t}\, x_{t-1},\, \beta_t I\right)$$

여기서 $\beta_t \in (0, 1)$는 사전에 정해진 noise schedule이다. 이 형태가 특별한 이유는 **분산 보존** 때문이다. 초기 데이터 분포가 unit variance를 가지면, 모든 $t$에서 $\mathbb{E}[\|x_t\|^2] \approx d$가 유지된다.

$$\mathbb{E}[\|x_t\|^2] = (1-\beta_t)\,\mathbb{E}[\|x_{t-1}\|^2] + \beta_t d \approx d$$

이 안정성 덕분에 학습이 수치적으로 발산하지 않는다. Schedule의 선택도 중요하다. Ho 2020의 linear schedule은 구현이 단순하지만, Nichol-Dhariwal 2021의 cosine schedule은 초반 정보 손실을 늦춰 더 나은 이미지 품질을 얻는다.

## Closed-Form — $O(T)$를 $O(1)$로

Markov chain을 따라 $t$번 반복 계산하는 것은 학습 중 너무 느리다. 핵심 통찰은 여러 번의 독립 가우시안 노이즈를 **하나의 가우시안으로 합칠 수 있다**는 것이다.

$\alpha_t := 1 - \beta_t$, $\bar{\alpha}_t := \prod_{s=1}^t \alpha_s$로 정의하면 다음 closed-form이 성립한다.

$$q(x_t \mid x_0) = \mathcal{N}\!\left(\sqrt{\bar{\alpha}_t}\, x_0,\, (1 - \bar{\alpha}_t) I\right)$$

<Theorem kind="theorem" number="1" title="Forward Closed-Form (귀납법)">
Forward Markov chain $x_t = \sqrt{1-\beta_t}\, x_{t-1} + \sqrt{\beta_t}\, \epsilon_t$에서, 임의의 $t$에 대해 다음이 성립한다.

$$x_t = \sqrt{\bar{\alpha}_t}\, x_0 + \sqrt{1 - \bar{\alpha}_t}\, \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$$
</Theorem>

<Proof>
$t=1$: $x_1 = \sqrt{\alpha_1} x_0 + \sqrt{1-\alpha_1} \epsilon_1 = \sqrt{\bar{\alpha}_1} x_0 + \sqrt{1-\bar{\alpha}_1} \epsilon_1$. 성립.

$t-1$에서 $x_{t-1} = \sqrt{\bar{\alpha}_{t-1}} x_0 + \sqrt{1-\bar{\alpha}_{t-1}} \epsilon'$가 성립한다고 가정하자. 그러면

$$x_t = \sqrt{\alpha_t}\, x_{t-1} + \sqrt{\beta_t}\, \epsilon_t = \sqrt{\alpha_t \bar{\alpha}_{t-1}}\, x_0 + \sqrt{\alpha_t(1-\bar{\alpha}_{t-1})}\, \epsilon' + \sqrt{\beta_t}\, \epsilon_t$$

두 독립 가우시안의 합의 분산은 $\alpha_t(1-\bar{\alpha}_{t-1}) + \beta_t = 1 - \alpha_t \bar{\alpha}_{t-1} = 1 - \bar{\alpha}_t$이므로, 합쳐서 단일 $\epsilon_{\text{new}} \sim \mathcal{N}(0,I)$로 표현된다. 따라서

$$x_t = \sqrt{\bar{\alpha}_t}\, x_0 + \sqrt{1-\bar{\alpha}_t}\, \epsilon_{\text{new}} \qquad \square$$
</Proof>

이 결과 덕분에 학습 중 임의의 시각 $t$를 샘플링하고 $x_t$를 단번에 생성할 수 있다. 샘플링 비용이 $O(T)$에서 $O(1)$로 줄어드는 것이 DDPM 학습의 실용성을 결정한다.

## Reverse Process — Score를 학습한다

Reverse process는 다음 문제로 귀결된다. "지금 $x_t$를 보고 있을 때, 어느 방향으로 노이즈를 빼야 $x_{t-1}$에 가까워지는가?" 이 방향이 바로 **score function**이다.

$$s(x_t, t) := \nabla_{x_t} \log p(x_t, t)$$

Anderson(1982)은 forward SDE에 대응하는 역방향 SDE가 다음과 같음을 보였다.

$$dx_t = \left[ f(t)\, x_t - g^2(t)\, \nabla_x \log p(x_t, t) \right] dt + g(t)\, d\bar{W}_t$$

Score는 density의 gradient이므로, 확률이 높은 쪽(데이터 분포)을 향한다. 신경망 $\epsilon_\theta(x_t, t)$가 이 score를 근사하도록 학습되는데, score와 noise 예측은 다음 관계로 연결된다.

$$\nabla_{x_t} \log q(x_t \mid x_0) = -\frac{\epsilon}{\sqrt{1-\bar{\alpha}_t}}$$

즉, **noise를 예측하는 것과 score를 학습하는 것은 수학적으로 동치**다. DDPM이 noise prediction loss를 쓰는 이유가 여기 있다 — noise는 항상 unit variance이므로 gradient flow가 안정적이다.

## Posterior와 학습 타깃

역과정의 학습 타깃은 true posterior $q(x_{t-1} \mid x_t, x_0)$이다. Bayes' rule과 가우시안의 곱 성질 덕분에 이 posterior 역시 가우시안이다.

$$q(x_{t-1} \mid x_t, x_0) = \mathcal{N}(\tilde{\mu}_t, \tilde{\beta}_t I)$$

$$\tilde{\mu}_t = \frac{\sqrt{\bar{\alpha}_{t-1}}\, \beta_t}{1 - \bar{\alpha}_t}\, x_0 + \frac{\sqrt{\alpha_t}(1 - \bar{\alpha}_{t-1})}{1 - \bar{\alpha}_t}\, x_t, \qquad \tilde{\beta}_t = \frac{1 - \bar{\alpha}_{t-1}}{1 - \bar{\alpha}_t}\, \beta_t$$

<Callout type="note" title="트레이드오프">
**Discrete vs Continuous**: DDPM의 $T=1000$ 이산 근사는 구현이 단순하고 DDIM 가속이 가능하다. 반면 Song et al.(2021)의 Score-SDE는 수학적 엄밀성과 exact likelihood를 얻는 대신 ODE solver가 필요하다. 실무에서는 discrete DDPM, 이론 분석에는 continuous SDE가 쓰인다. **Fixed schedule의 한계**: $\beta_t$를 미리 고정하면 closed-form이 존재하지만 문제마다 최적 schedule이 다를 수 있다. Cosine schedule은 이 간극을 고정 + 단순한 방식으로 좁혔다.
</Callout>

$t$가 클수록 $\tilde{\mu}_t$에서 $x_t$의 가중치가 커지고 $x_0$의 가중치는 줄어든다. 직관적으로, 노이즈가 많이 쌓인 상태에서는 원본 정보보다 현재 관찰이 더 신뢰할 만하다.

## 정리

- Diffusion Model의 설계는 브라운 운동의 분산 증가 → forward process, Anderson(1982)의 Reverse SDE → score matching, DDPM의 closed-form → $O(1)$ 샘플링이라는 세 번의 번역을 거쳐 완성된다.
- $\bar{\alpha}_t = \prod \alpha_s$는 단순한 표기가 아니라 "여러 가우시안 노이즈를 하나로 합칠 수 있다"는 사실의 압축이다.
- Noise prediction과 score matching은 같은 목적함수의 두 이름이다.
- True posterior의 closed-form이 존재하기 때문에 DDPM의 학습 타깃이 명확하다. 이 closed-form이 없었다면 학습 시간은 $T$배 늘어났을 것이다.

다음 글에서는 이 posterior로부터 ELBO를 어떻게 분해하는지, 그리고 DDPM의 simplified loss가 왜 이론적으로 정당화되는지 추적한다.
